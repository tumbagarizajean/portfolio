Free Time Determination — Process Redesign

Processing 4–6 vessels a day meant repeating an 8–9 tool lookup sequence per vessel, for roughly six hours total. I consolidated the source data into one master file that a macro pulls from, cutting per-vessel processing while keeping the one genuinely real-time check manual.

AI Case-Resolution Accuracy — SOP Redesign

A generative AI tool was recommending case resolutions off an SOP written for human judgment, not machine logic. I worked directly with the agents using it to find what wasn't resolving cleanly, then mapped every branch scenario I could anticipate — not just the ones that had already gone wrong — into explicit step-by-step conditional logic for the tool to follow.
